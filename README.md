# Robotika

Repository ini berisi kumpulan tugas dan eksperimen Robotika menggunakan Kit iMCLab.

## Struktur Folder

- **2. IMCLAB python arduino**

- **3. IMCLAB blynk**  
  Pemrograman dan pengendalian iMCLab berbasis Blynk.

- **4. IMCLAB OTA Blynk**
