# 4. IMCLAB OTA Blynk

Modul dasar iMCLab dengan koneksi Blynk dan pembaruan program melalui Over-The-Air (OTA).

## File
- `ota_blynk.ino` : Program ESP32 dengan ArduinoOTA.
- `secrets.example.h` : Template kredensial.

Pastikan perangkat dan komputer berada pada jaringan Wi-Fi yang sesuai sebelum melakukan pembaruan OTA.
